FFMPEG

От одной строчки кода французского программиста в 2000 году — до движка, на котором держится видео половины интернета.

Что это такое

Швейцарский нож для видео и звука

FFmpeg — это набор свободных библиотек и консольных инструментов с открытым исходным кодом, которые умеют записывать, конвертировать и передавать цифровое аудио и видео практически в любом существующем формате.

Проект изначально создавался под Linux-системы, но сегодня собирается практически под любую операционную систему — Windows, macOS, BSD и другие. FFmpeg распространяется под лицензиями GNU LGPL или GNU GPL — конкретный вариант зависит от того, какие необязательные компоненты подключены при сборке. Сами разработчики советуют по возможности брать свежую версию из Git-репозитория: именно там новые возможности и исправления появляются раньше всего, — но для подавляющего большинства задач вполне достаточно и обычного стабильного релиза.

libavcodec

Кодирует и декодирует аудио- и видеопотоки — сердце всего проекта, десятки поддерживаемых кодеков в одной библиотеке.

libavformat

Мультиплексирует и демультиплексирует данные в медиаконтейнеры: MP4, MKV, WebM, MOV и множество других.

libavfilter

Обрабатывает и изменяет видео и звук через граф фильтров — масштабирование, обрезка, наложение, цветокоррекция.

libavutil

Общие вспомогательные функции: математика, работа с памятью, метаданные — используется всеми остальными библиотеками.

libswscale

Масштабирование изображений и конвертация между цветовыми пространствами и форматами пикселей.

libswresample

Передискретизация, конвертация форматов сэмплов и микширование каналов аудиопотока.

Установка

Поставить FFmpeg за одну команду

Официально FFmpeg распространяется в первую очередь как исходный код — готовые исполняемые файлы собирают сторонние мейнтейнеры, ссылки на которых опубликованы на официальном сайте.

Актуальный стабильный релиз:  FFmpeg 8.1.2 «Hoare»
Debian / Ubuntu
sudo apt update sudo apt install ffmpeg

Пакет находится в репозитории universe (Ubuntu) или main (Debian) — обычно уже подключён по умолчанию.

Arch Linux
sudo pacman -S ffmpeg
Fedora / RHEL

Из-за патентных ограничений на часть кодеков пакета нет в базовых репозиториях — сначала подключите RPM Fusion, затем ставьте как обычно:

sudo dnf install ffmpeg
Универсальные статические сборки

Если в репозитории вашего дистрибутива устаревшая версия — на странице загрузок ffmpeg.org указана статическая сборка BtbN/FFmpeg-Builds на GitHub, работает на любом дистрибутиве без установки зависимостей.

Через Homebrew
brew install ffmpeg

Homebrew — самый простой путь. Альтернатива без него — официально указанные на ffmpeg.org статические сборки с сайта evermeet.cx.

Готовые сборки

На странице загрузок ffmpeg.org для Windows официально указаны две ссылки на сторонние сборки: gyan.dev и BtbN на GitHub. Скачайте архив, распакуйте в удобную папку (например, C:\ffmpeg) и добавьте путь к вложенной папке bin в переменную среды PATH — после этого команда ffmpeg станет доступна из любой директории.

Клонировать официальный репозиторий
git clone https://git.ffmpeg.org/ffmpeg.git ffmpeg cd ffmpeg ./configure --enable-gpl --enable-libx264 --enable-libmp3lame make -j$(nproc) sudo make install

Флаги --enable-... подключают внешние библиотеки кодеков — без них соберётся только базовый функционал.

Проверка установки (любая ОС)
ffmpeg -version

Если всё поставилось верно, в выводе появится номер версии и список библиотек, с которыми она была собрана.

История создания

Путь от личного проекта до инфраструктуры интернета

Название сочетает «FF» — от Fast Forward, перемотки вперёд — и MPEG, аббревиатуру экспертной группы, стандартизировавшей большинство современных форматов видео и аудио.

2000

Первая строчка кода

Французский программист Fabrice Bellard под псевдонимом «Gérard Lantau» начинает писать FFmpeg как личный инструмент для конвертации между мультимедийными форматами в Linux. 20 декабря выходит первый публичный релиз.

2001

Рождение libavcodec

Начинается активная разработка. В проект входит библиотека libavcodec, впервые собравшая кодеки для десятков форматов видео и аудио в одном месте вместо десятков разрозненных реализаций.

2003–2004

Смена руководителя

Bellard передаёт руководство проектом Michael Niedermayer, который возглавит разработку на следующее десятилетие. Часть будущих контрибьюторов FFmpeg приходит из смежного проекта MPlayer.

2011

Форк Libav

Разногласия по поводу управления проектом приводят к расколу: часть разработчиков создаёт форк под названием Libav. Спор растягивается на годы, но большинство дистрибутивов со временем возвращаются к FFmpeg.

2014

Тысяча багов от Google

Инженеры Google с помощью автоматизированного fuzzing-тестирования находят и помогают устранить более тысячи ошибок в кодовой базе — один из крупнейших вкладов в надёжность проекта.

2015

Коллективное управление

Niedermayer покидает пост руководителя, и проект окончательно переходит к модели коллективного управления командой независимых мейнтейнеров.

Сегодня

Незаметный двигатель интернета

FFmpeg лежит в основе YouTube, Netflix, VLC, Chrome, Firefox и тысяч других продуктов — оставаясь одним из самых важных, но незаметных инструментов современного интернета.

КОНВЕРТАЦИЯ
ВИДЕО

Меняем контейнер и кодек видео — из любого формата в любой, одной командой

Название файла

ffmpeg configuration example

Что делает эта команда

  • -i {{file}}указывает исходный файл, который нужно перекодировать.
  • -c:v libx264кодирует видеодорожку кодеком H.264 через энкодер x264 — самый совместимый видеокодек на сегодняшний день.
  • -crf 23Constant Rate Factor — управляет соотношением качества и размера. Диапазон 0–51: меньше значение — выше качество и больше вес файла. 18–28 — рабочий диапазон для большинства задач.
  • -preset mediumкомпромисс между скоростью кодирования и эффективностью сжатия. Более медленные пресеты (slow, slower) дают меньший файл при том же качестве.
  • -c:a aac -b:a 192kкодирует звуковую дорожку в AAC с битрейтом 192 кбит/с.
Как изменить под себя: чтобы получить другой формат на выходе, поменяйте расширение output.mp4 на нужное — например, для WebM возьмите -c:v libvpx-vp9 -c:a libopus output.webm. Для более высокого качества уменьшите значение CRF, для меньшего размера файла — увеличьте.

Что делает эта команда

ВИДЕО

Уменьшаем размер файла, сохраняя приемлемое визуальное качество

Название файла

ffmpeg configuration example

Что делает эта команда

  • -crf 28более высокое значение CRF, чем при обычной конвертации — заметно уменьшает размер файла ценой части визуальной детализации.

ОБРЕЗКА
ВИДЕО

Вырезаем нужный фрагмент по временным меткам без повторного кодирования

Название файла

ffmpeg configuration example

Что делает эта команда

  • -ss 00:00:10начальная точка обрезки, указанная до -i — так поиск позиции во входном файле происходит быстрее и точнее.
  • -to 00:00:30конечная точка обрезки: абсолютное время от начала файла, а не длительность фрагмента.
  • -c copyкопирует потоки видео и аудио без перекодирования — обрезка происходит почти мгновенно и без потери качества.
Как изменить под себя: замените значения времени на нужные в формате чч:мм:сс. Если точка обрезки должна прийтись точно на нужный кадр, а не на ближайший ключевой кадр, уберите -c copy — тогда ffmpeg перекодирует видео и сможет резать с точностью до кадра.

GIF

Превращаем отрывок видео в компактную зацикленную анимацию

Название файла

ffmpeg configuration example

Что делает эта команда

  • fps=15снижает частоту кадров до 15 в секунду — достаточно для плавности и заметно меньше веса файла.
  • scale=480:-1уменьшает ширину картинки до 480px, сохраняя пропорции — значение -1 подставляет высоту автоматически.
  • flags=lanczosкачественный алгоритм масштабирования, лучше сохраняющий детали при уменьшении.
Как изменить под себя: формат GIF ограничен палитрой в 256 цветов, поэтому картинка может выглядеть скромнее исходника. Для заметно лучшего качества цвета используйте двухэтапный процесс с фильтрами palettegen и paletteuse — FFmpeg сгенерирует оптимальную палитру именно под ваш ролик перед кодированием.

ffmpeg configuration example

Что делает эта команда

ВИДЕО

Объединяем несколько файлов в один без потери качества

Имя итогового файла

Перед запуском создайте рядом текстовый файл list.txt, где каждая строка — file 'имя.mp4' для каждого из склеиваемых видео по порядку.

ffmpeg configuration example

Что делает эта команда

  • -f concatвключает демуксер конкатенации — специальный режим для объединения файлов по списку.
  • -safe 0разрешает использовать в списке пути к файлам вне текущей папки.
  • -i list.txtфайл со списком видео для склейки — по одному на строку, в нужном порядке.
  • -c copyкопирует потоки без перекодирования — быстро, но требует, чтобы все файлы были в одинаковом кодеке и разрешении.
Как изменить под себя: если исходники отличаются кодеком, разрешением или частотой кадров, уберите -c copy — ffmpeg перекодирует и склеит их в единый согласованный формат (займёт больше времени).

Разворачиваем изображение на 90, 180 или 270 градусов

Название файла

ffmpeg configuration example

Что делает эта команда

  • transpose=1поворот на 90° по часовой стрелке — самый частый случай для видео, снятого телефоном боком.

РАЗМЕРА

Меняем разрешение видео, не трогая кодек звука

Название файла

ffmpeg configuration example

Что делает эта команда

  • scale=1280:-2масштабирует ширину до 1280px; высота вычисляется автоматически с сохранением пропорций. -2 (в отличие от -1) гарантирует чётное число — это требование большинства видеокодеков.

ИЗМЕНЕНИЕ
СКОРОСТИ

Ускоряем или замедляем видео вместе со звуком

Название файла

ffmpeg configuration example

Что делает эта команда

  • setpts=0.5*PTSмножитель для видео: значение меньше 1 ускоряет ролик, больше 1 — замедляет (0.5 = вдвое быстрее).
  • atempo=2.0множитель темпа звука — должен быть обратным к setpts, иначе звук и видео разойдутся по времени.
  • -map "[v]" -map "[a]"явно указывает, какие потоки после фильтров попадут в итоговый файл.
Как изменить под себя: фильтр atempo работает только в диапазоне 0.5–2.0 за одно применение. Для более сильного ускорения соедините несколько фильтров подряд: atempo=2.0,atempo=2.0 даст ускорение в 4 раза.

НАЛОЖЕНИЕ
ЛОГОТИПА

Добавляем изображение поверх видео — водяной знак, значок канала или подпись

Название файла

Логотип должен лежать рядом под именем logo.png — PNG с прозрачным фоном подходит лучше всего.

ffmpeg configuration example

Что делает эта команда

  • -i logo.pngвторой входной файл — изображение, которое будет наложено на видео.
  • -filter_complex "overlay=10:10"фильтр overlay накладывает второй поток поверх первого; числа — отступ от левого верхнего угла в пикселях.
Как изменить под себя: чтобы разместить логотип в правом нижнем углу: overlay=W-w-10:H-h-10 (W/H — размер видео, w/h — размер логотипа, ffmpeg подставит их сам). Чтобы предварительно уменьшить логотип: -filter_complex "[1:v]scale=150:-1[wm];[0:v][wm]overlay=10:10".

СТАБИЛИЗАЦИЯ
ВИДЕО

Убираем тряску камеры — сглаживаем дрожащую съёмку с рук

Название файла

ffmpeg configuration example

Что делает эта команда

  • -vf "deshake"встроенный фильтр стабилизации: анализирует смещение кадров относительно друг друга и компенсирует дрожание камеры, ничего не устанавливая дополнительно.
Как изменить под себя: deshake прост, но справляется только с лёгким дрожанием. Для сильной тряски используйте библиотеку vidstab в два прохода: сначала -vf vidstabdetect=shakiness=8 для анализа траектории движения в отдельный файл, затем -vf vidstabtransform=smoothing=30 для самой стабилизации — заметно мощнее, но требует сборки ffmpeg с флагом --enable-libvidstab.

Меняем формат картинки — JPG, PNG, WebP и другие, одной командой

Название файла

ffmpeg configuration example

Что делает эта команда

  • -i {{file}}исходное изображение — ffmpeg сам определяет формат по содержимому файла, а не по расширению.
  • -quality 90качество сжатия для форматов с потерями (JPEG, WebP): шкала 0–100, где меньше значение — выше сжатие и ниже качество.
  • output.webpформат результата определяется расширением выходного файла — так же работает и для .jpg, .png, .bmp, .tiff.
Как изменить под себя: для PNG опция -quality не действует — вместо неё используйте -compression_level 100 (0–100, где больше — сильнее и медленнее сжатие без потерь). Для пакетной конвертации целой папки в Linux/macOS подойдёт: for f in *.png; do ffmpeg -i "$f" "${f%.png}.webp"; done.

Что делает эта команда

  • scale=800:-1уменьшает ширину изображения до 800px; высота подбирается автоматически с сохранением пропорций.
Как изменить под себя: для фото (в отличие от видео) чётность значения не обязательна, поэтому можно использовать именно -1, а не -2. Чтобы задать точную высоту вместо ширины: scale=-1:600. Чтобы растянуть без сохранения пропорций: укажите оба числа явно, например scale=800:600.

Изображения должны быть пронумерованы по порядку: photo001.jpg, photo002.jpg и так далее.

ffmpeg configuration example

Что делает эта команда

  • -framerate 1/3задаёт, как долго показывается каждое фото: 1/3 означает один кадр на 3 секунды.
  • -i photo%03d.jpgшаблон имени входных файлов — %03d подставляет номер с ведущими нулями (001, 002, 003…).
  • -pix_fmt yuv420pформат цветовых данных, обязательный для совместимости с большинством плееров и площадок — без него видео может не воспроизвестись в некоторых браузерах.
Как изменить под себя: чтобы каждое фото показывалось дольше или короче, поменяйте дробь у -framerate — например, 1/5 даст 5 секунд на кадр. Чтобы добавить плавные переходы между фото, используйте фильтр xfade между соседними кадрами.

ВИДЕО­КОДЕКИ

Какой кодек выбрать в FFmpeg под свою задачу

H.264 / AVC · libx264

Самый совместимый видеокодек, поддерживается почти всеми устройствами и плеерами. Хороший выбор по умолчанию для большинства задач.

H.265 / HEVC · libx265

Примерно вдвое эффективнее H.264 при том же качестве, но медленнее кодируется и хуже поддерживается старыми устройствами.

VP9 · libvpx-vp9

Открытый кодек от Google, основа формата WebM, широко используется на YouTube.

AV1 · libaom-av1 / libsvtav1

Самый новый из массовых открытых кодеков — лучшее сжатие среди перечисленных, но и самое медленное кодирование.

FFV1

Кодек без потерь (lossless), разработанный внутри самого проекта FFmpeg — используется в архивации и цифровой реставрации.

АУДИО­КОДЕКИ

Какой звуковой кодек выбрать в FFmpeg под свою задачу

AAC · aac / libfdk_aac

Стандарт де-факто для видео и стриминга, хорошее качество уже на средних битрейтах.

MP3 · libmp3lame

Самый универсальный формат, поддерживается буквально везде — от старых плееров до любых современных устройств.

Opus · libopus

Современный кодек для голоса и потокового звука, отличное качество на низких битрейтах.

Vorbis · libvorbis

Свободный кодек, предшественник Opus, обычно используется вместе с Ogg-контейнером.

FLAC · flac

Сжатие без потерь — звук идентичен оригиналу, но файлы заметно крупнее, чем при lossy-кодировании.
